# Rocket Vibez

Clothes for the loud years. Bold graphic tees and hoodies for kids, teens, and grown-ups.

- Live site (test phase, no payments yet): https://rocketvibez.grok.me
- Socials: Instagram, TikTok @therocketvibez, plus a Facebook page
- Contact: therocketvibez@gmail.com

## What's here
- `docs/grok-build/`: launch brief and paste-ready change specs for the Grok Build app
- `docs/research/`: pricing and sourcing research (the kids/teen report is current)
- `docs/brand-kit.md`: early brand kit v0.1 (adult-streetwear era, partly outdated)
- `brand/logo/`: the current logo plus four rocket-icon options
- `brand/social/`: profile picture and first-post image
- `scripts/`: the Python/PIL script that built the rocket options

## App source
The storefront is built and hosted in Grok Build. Its source code isn't in this repo yet; export it from Grok Build and add it under `app/`.
